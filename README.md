# Explore Tracking Sentul 🌿🥾

Landing page resmi dan interaktif untuk jasa pemandu wisata alam **Explore Tracking Sentul** (Kang Rudi / Ruddy Outdoor Adventure).

---

## ✨ Fitur Utama

- **Hero & Profil Pemandu**: Menampilkan ringkasan kredibilitas, jam terbang, dan filosofi layanan ramah keluarga.
- **Rute Populer**: Pilihan trek Curug Leuwi Hejo, Curug Hordeng, Goa Garunggang, Bukit Paniisan, dan Cisadon.
- **Galeri Dokumentasi**: Foto asli dokumentasi trip klien dan keindahan panorama alam Sentul.
- **Integrasi WhatsApp Langsung**: Tombol konsultasi cepat dengan format pesan otomatis.
- **Fasilitas & Keamanan**: Detail paket (guide lokal, tiket wisata, tongkat trekking, P3K, dokumentasi).
- **Video Demo**: Demo rekaman navigasi halaman penuh (`demo_explore_tracking_sentul.mp4`).

---

## 🛠️ Teknologi

- **HTML5 & Vanilla JavaScript**: Struktur semantik dan interaksi ringan (mobile menu, FAQ accordion).
- **Tailwind CSS (CDN)**: Styling utilitas modern tanpa build step.
- **FontAwesome & Lucide Icons**: Ikonografi navigasi dan fitur.
- **Google Fonts (Plus Jakarta Sans)**: Tipografi modern dan mudah dibaca.

---

## 🚀 Menjalankan Secara Lokal

Cukup clone repositori dan buka file `index.html` langsung di browser, atau gunakan server statis sederhana:

```bash
# Clone repository
git clone https://github.com/allam1768/ExplorTrakingSentul.git
cd ExplorTrakingSentul

# Jalankan server lokal (opsional)
python3 -m http.server 3000
```

Buka `http://localhost:3000` pada peramban web.
